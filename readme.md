# Supermarket Sales Analysis – Excel Project

## 📌 Project Overview
This project focuses on analysing supermarket sales data using Microsoft Excel. The goal is to understand sales performance, identify top-performing products and categories, and compare monthly and location-wise sales.

An interactive Excel dashboard was created using PivotTables, PivotCharts, formulas and slicers.

## 📊 Dataset Information
- **Total Records:** 100 transactions
- **Total Columns:** 9

### Dataset Columns
- Order ID
- Product
- Category
- Quantity
- Price
- Sales
- Date
- Location
- Payment Method

## 🛠️ Tools & Skills Used
- Microsoft Excel
- Excel Formulas: SUM, AVERAGE, COUNTA
- PivotTables
- PivotCharts
- Data Analysis
- Interactive Slicers
- Dashboard Creation

## 📈 Key Analysis
The project analyses:
1. Total Sales
2. Average Sales
3. Total Orders
4. Top-performing Products
5. Category-wise Sales Performance
6. Monthly Sales Trends
7. Location-wise Sales Performance

## 📊 Dashboard Features
The interactive dashboard includes:

- KPI Cards for Total Sales, Average Sales and Total Orders
- Sales by Product Chart
- Sales by Category Chart
- Sales by Location Chart
- Monthly Sales Trend Chart

### Interactive Filters
- Location
- Category
- Payment Method

These slicers allow users to filter the dashboard and explore different sales patterns.

## 🎯 Project Objective
The main objective was to practise real-world data analysis using Excel and develop an interactive dashboard that helps users understand supermarket sales performance.
